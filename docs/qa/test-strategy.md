# Estrategia de pruebas

## Niveles

- Unitarias.
- Integración.
- Contrato.
- Componentes.
- E2E.
- Campo móvil.
- Seguridad.
- Rendimiento.
- Recuperación.

## Riesgos prioritarios

1. Mezcla entre empresas.
2. Duplicación offline.
3. Pérdida de visitas o ventas.
4. Geocerca incorrecta.
5. Rastreo fuera de jornada.
6. Ubicación antigua mostrada como actual.
7. WebSocket sin autorización.
8. Reintentos infinitos.
9. Importaciones inseguras.
10. Reportes inconsistentes.

Toda evidencia registra versión, datos, pasos, esperado y obtenido.
