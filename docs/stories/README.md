## Uso recomendado

1. Seleccionar una historia de integración.
2. Vincular las historias Backend, Frontend y Mobile necesarias.
3. Refinar REST, eventos, WebSocket y sincronización.
4. Implementar y validar por plataforma.
5. Ejecutar QA E2E y DoF.

Las historias técnicas se expresan con la misma plantilla para mantener un backlog único y trazable.
