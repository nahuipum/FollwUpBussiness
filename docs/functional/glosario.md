# Glosario

| Término | Definición |
|---|---|
| Empresa / tenant | Organización cliente cuyos datos permanecen aislados. |
| Jornada | Periodo activo durante el cual puede rastrearse al vendedor. |
| Ruta | Secuencia planificada de clientes para una fecha y vendedor. |
| Punto de ruta | Cliente incorporado a una ruta con orden y estado. |
| Geocerca | Radio permitido alrededor del cliente. |
| Check-in | Inicio de visita validado por jornada, ubicación y permisos. |
| Check-out | Cierre de visita con resultado obligatorio. |
| Ubicación desactualizada | Posición cuya antigüedad impide tratarla como actual. |
| Idempotencia | Reintentar una operación sin crear duplicados. |
| Outbox | Patrón para publicar eventos de forma consistente con una transacción. |
| DLQ | Cola de mensajes que agotaron reintentos. |
| DoF | Verificación final de que la historia está terminada. |
