# Documentación funcional

Esta carpeta contiene la fuente funcional del producto.

- `contrato-funcional.md`: alcance, reglas de negocio, requerimientos y criterios del MVP.
- `matriz-trazabilidad.md`: relación entre requerimientos e historias.
- `glosario.md`: términos compartidos.

Las historias no deben modificar silenciosamente el comportamiento general. Si una decisión cambia el producto, primero se actualiza el contrato funcional y luego el backlog afectado.
