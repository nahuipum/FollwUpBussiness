Anotación del mockup · no es UI de producto

Confirmación: la historia dice “Confirma”, pero no define si exige aprobación previa. Hoy el formulario envía el PATCH directamente; solo hay acuse de resultado. Queda pendiente aclarar ese criterio antes de agregar otro flujo.

Auditoría: el backend registra COMPANY_SETTINGS_UPDATED; esta pantalla no consulta ni muestra historial. Falta definir si la auditoría debe verse aquí y con qué acceso.

Permisos: el contrato y backend permiten GET a COMPANY_ADMIN, SUPERVISOR y SELLER; la página React actual deniega SELLER. La discrepancia queda abierta y este mockup no cambia permisos.

Radio configurable: RN-006 habla de configuración por empresa, mientras ADR-016 y el contrato fijan 100 m para el MVP. Aquí se refleja la política vigente; el alcance futuro requiere definición.
