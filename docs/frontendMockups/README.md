# Mockups Frontend

Esta carpeta contiene mockups HTML estáticos que sirven como referencia visual
para las historias Frontend.

## Convención

- Nombrar cada mockup como `<HU-ID>.html`, por ejemplo `FE-001.html`.
- Durante Desarrollo Frontend se busca primero el archivo exacto de la HU.
- Si existe, su composición, tokens visuales, responsive y estados mostrados
  guían la implementación; la HU, contratos y accesibilidad mantienen
  precedencia funcional.
- Si no existe, revisar los mockups presentes para conservar sus patrones. El
  agente de Desarrollo Frontend puede crear `<HU-ID>.html` como propuesta
  estática para que sirva de referencia en adelante.
- No usar un mockup para inventar reglas de negocio, permisos o datos; ni
  modificar uno existente fuera del alcance de la historia.
