Opciones de presentación para mapas

Las tres pueden convivir según la tarea; la primera debe ser la vista operativa principal.

Recomendada

1. Espacio operativo mapa + ruta

Mapa dominante con itinerario persistente. Ideal para planificar, ordenar paradas, revisar cobertura y actuar sin abrir otro contexto.

2. Vista dividida mapa + listado

Mitad datos, mitad mapa. Útil para buscar, comparar clientes y seleccionar varios puntos antes de armar una ruta.

3. Modal de ubicación rápida

Mapa acotado sobre la pantalla actual. Conveniente para confirmar o corregir un punto, no para gestionar rutas completas.

Sistema visual definitivo

SaaS profesional, claro y sereno. La actualización permanece en la topbar; el tema vive junto a utilidades globales y perfil, donde mantiene alcance transversal.
