2

Alerta inline de validación Caso 422 · Información inválida

Para qué sirve: resume errores de entrada y dirige al usuario hacia los campos marcados, sin exponer detalles técnicos ni información sensible.

Revisa los campos marcados e inténtalo nuevamente.
3

Diálogo modal de sesión terminada Caso 401 · Sesión no válida

Para qué sirve: interrumpe de manera segura una tarea cuando la sesión ya no es válida y conduce nuevamente al inicio de sesión sin revelar información interna.

Tu sesión terminó

Por seguridad, inicia sesión nuevamente para continuar.

4

Estado de página · Acceso denegado Caso 403 · Permiso insuficiente

Para qué sirve: reemplaza el contenido solicitado cuando un usuario autenticado no tiene permiso para acceder a esa sección.

No tienes permiso para acceder

Esta sección no está disponible para tu perfil actual.

5

Estado de página · No encontrado Caso 404 · Ruta o recurso inexistente

Para qué sirve: comunica que la página solicitada no existe, cambió de dirección o dejó de estar disponible.

No encontramos esta página

Es posible que el enlace ya no exista o haya cambiado.
