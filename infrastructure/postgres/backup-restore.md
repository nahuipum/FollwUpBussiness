# Backup y recuperación

## Backup

- Automatizado.
- Cifrado.
- Retención definida.
- Verificación.
- Copia fuera del entorno principal.

## Restore

1. Restaurar en entorno aislado.
2. Validar migraciones.
3. Ejecutar pruebas de consistencia.
4. Medir y documentar RPO/RTO.

Una copia no se considera válida hasta ser restaurada.
