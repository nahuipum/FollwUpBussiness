# Estándar de observabilidad

El correlationId se propaga entre clientes, API, dominio, outbox, RabbitMQ, consumidores y WebSocket.

No registrar contraseñas, tokens, documentos completos, payloads completos de ventas ni coordenadas innecesarias.

SLO inicial: disponibilidad 99,5 % y operaciones comunes idealmente menores a 3 segundos bajo carga normal.
